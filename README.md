# Графіки відключень — Норівка

Статичний сайт для перегляду графіків черги 1.1 Дніпровських електромереж
та повідомлень ДТЕК для с. Любимівка, вул. Центральна, будинок 1.

Сайт: https://norivka.github.io/.

## Дані

Сайт отримує JSON безпосередньо з Cloudflare Worker:
https://norivka-outages.numrut.workers.dev/.
Адреса задана у `data-config.js`.

- `/data/dtek-outages.json` — графік ДТЕК.
- `/data/dtek-address.json` — адресне повідомлення ДТЕК.
- `/data/outages.json` — графік ЯСНО.

Сторінка перевіряє дані кожні 5 хвилин, поки вона видима, та відразу після
повернення до неї. Запити відвідувачів читають готові дані й не запускають
отримання інформації від постачальників. API дозволяє CORS для цього сайту.

Backend, cron, сховище, обробка даних та розсилка зберігаються в окремому
приватному репозиторії **norivka/outages**. Локальна директорія — `../outages`.
Worker перевіряє джерела кожні 5 хвилин. При недоступності джерела віддає останні
успішно отримані дані зі збереженим часом оновлення. Для браузерного отримання
ДТЕК діє добовий бюджет; він може обмежувати свіжість даних при блокуванні HTTP.

Цей репозиторій містить лише сайт, його тести й публічні налаштування.
Оновлення графіків не потребує комітів або перебудови GitHub Pages.

## Push-сповіщення

Натисніть «🔔 Увімкнути сповіщення» та дозвольте їх у браузері.
Підпискою й доставкою керує OneSignal. Домен сайту та App ID залишаються
незмінними під час перенесення backend; повторно підписуватися не потрібно.

Сповіщення надсилаються про зміни графіка й адресного повідомлення ДТЕК.
Для наявного стабілізаційного повідомлення зміни тексту або часу не створюють
повторного адресного push. Дані ЯСНО не створюють сповіщень.
Початковий актуальний стан після міграції фіксується без розсилки.

На iPhone/iPad спочатку додайте сайт на початковий екран, відкрийте його звідти
та ввімкніть сповіщення. Публічні налаштування — у `push-config.json`;
секретний REST API key зберігається лише в backend.

## Розробка

```sh
node --test *.test.js
python3 -m http.server 8000
```

Продакшн API дозволяє браузерні запити з `https://norivka.github.io`.
Для локального перегляду даних запустіть backend локально з відповідним CORS
або підставте тестові JSON. Секрети та серверний код сюди не додаються.

GitHub Pages публікує статичні файли. Workflow `Test site` перевіряє лише frontend.
